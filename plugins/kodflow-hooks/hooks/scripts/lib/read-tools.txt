# read-tools.txt — the tools the triage gate always lets through: they read,
# they never write. Read by on-tool.sh (its fast path and its gate, through
# readlist.sh) and by the mod (register.ts), so the three agree.
#
# One exact tool name per line, surrounding blanks (a CR included) ignored.
# A line ending in `*` is a prefix; only the two task-tool prefixes below are
# allowed one (tests/mod and test_hooks.sh hold it), and a bare `*` is
# ignored by both readers: it would list every tool. A tool absent from this list is a write: the gate refuses it
# while a message waits for its task, and the mod notes the attempt
# (triage-wrote). Bash is not here: the gate lets it through on its own
# checks, and it marks nothing.
#
# A forge tool is listed only by its exact name, never by a pattern:
# mcp__github__mark_all_notifications_read ends in _read and writes.
